# 2048 Studio — Tactile Puzzle Edition

세라믹 질감의 모던한 디자인과 부드러운 타일 물리·프로시저럴 사운드를 결합한 상용 퀄리티 2048 웹 퍼즐 게임입니다. 별도 빌드 도구 없이 순수 HTML, CSS, ES Modules로 구성되어 GitHub Pages·Vercel·Cloudflare Pages 등에 즉시 배포할 수 있습니다.

## 주요 기능

- **4가지 큐레이션 테마**: Porcelain (라이트) · Obsidian (다크) · Matcha (세이지 그린) · Sandstone (웜 클레이)
- **5가지 게임 모드**:
  - `4×4` 클래식 (목표 2048)
  - `피보나치` (`1+1=2`, `1+2=3`, `2+3=5` … 인접 피보나치 수 병합, 목표 2584, 실시간 수열 가이드 리본 포함)
  - `오늘의 도전` (날짜 기반 시드 PRNG로 매일 동일한 시작/스폰 시퀀스 제공)
  - `3×3` 스피드 (목표 512)
  - `5×5` 마라톤 (목표 4096)
- **촉각적 인터랙션 & 연출**:
  - `translate3d` 기반 부드러운 슬라이딩·병합 팝 애니메이션
  - 이동 불가 방향 입력 시 미세한 보드 벽면 반동 피드백
  - 연속 병합 콤보 배지, 목표 타일 진행률 바, 고티어 마일스톤 파티클 연출
  - Web Audio API로 실시간 합성하는 펜타토닉 마림바 병합 사운드 (외부 오디오 에셋 0개)
- **편의성 & 기록 저장**:
  - 되돌리기(Undo) 지원, 모드별 자동 저장 및 이어하기
  - 플레이 통계 & 세라믹 타일 도감 모달
  - 결과 이모지 보드 클립보드 공유
  - 키보드(`↑↓←→`, `WASD`, `HJKL`, `Z`, `M`, `R`), 모바일 스와이프, 마우스 드래그 플릭 모두 지원

## 구조

```
├── index.html           # 시맨틱 마크업 & 접근성 레이아웃
├── styles/
│   ├── tokens.css       # 디자인 토큰 & 4개 테마 팔레트
│   └── main.css         # 반응형 레이아웃, 애니메이션, 모달 스타일
├── src/
│   ├── engine.js        # 순수 2048 게임 엔진 & 시드 PRNG
│   ├── renderer.js      # GPU 가속 타일 & 캔버스 파티클 렌더러
│   ├── sound.js         # Web Audio API 프로시저럴 사운드 엔진
│   ├── storage.js       # LocalStorage 자동 저장 & 통계 관리
│   ├── input.js         # 키보드·터치·마우스 통합 입력 컨트롤러
│   └── app.js           # 앱 컨트롤러
└── tests/
    └── engine.test.mjs  # Node 내장 테스트 스위트
```

## 테스트 실행

```bash
node --test tests/engine.test.mjs
```
